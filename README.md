# Just Search XHS

适用于 Chrome 和 Edge 的小红书网页版扩展。

## 功能

- 隐藏首页推荐，保留居中搜索。
- 收起侧栏，自定义菜单显示。
- 默认隐藏「猜你想搜」，可隐藏通知红点。
- 设置自动保存。

## 使用

1. 下载仓库 ZIP 并解压。
2. 打开 `chrome://extensions/` 或 `edge://extensions/`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
4. 刷新小红书网页，点击扩展图标调整设置。

更新时，将新文件覆盖到原目录，重新加载扩展并刷新页面。
